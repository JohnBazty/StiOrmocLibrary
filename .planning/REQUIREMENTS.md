# Requirements

- **RES-MAINT-01**: Librarians can set how long a ready reservation is held for pickup.
- **RES-MAINT-02**: Librarians can set an optional limit on how long a reservation may wait in the queue.
- **NOTIF-01**: The borrower gets a notice when a librarian records a book return.
- **NOTIF-02**: The user gets a notice when a librarian grants a clearance override.
- **NOTIF-03**: The user gets a notice when a librarian revokes a clearance override.
- **NOTIF-04**: The borrower gets a notice when an in-library use starts.
- **NOTIF-05**: The borrower gets a notice when an in-library use is overdue for hand-back.
- **NOTIF-06**: Users with an open print request get a notice when printing is paused.
- **NOTIF-07**: Users with an open print request get a notice when printing resumes.
- **NOTIF-08**: The Borrow confirmed notice has a source, link and dedupe key.
- **NOTIF-09**: Every new notice is saved in the action's transaction, once per event.
